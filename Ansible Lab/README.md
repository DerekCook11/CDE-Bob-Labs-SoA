# Ansible Lab

This lab demonstrates an AI-assisted development and deployment workflow using IBM Bob. Starting from a bare RHEL 9 VM, you will use Bob to provision the host with Ansible roles, scaffold a Node.js REST API, containerize it, and deploy it to Podman — all through natural-language prompts.

**Prerequisites:** A RHEL 9 VM with internet access and `sudo` privileges, and IBM Bob connected to this workspace.

**Lab instructions:** [Lab Instructions/lab.md](Lab%20Instructions/lab.md)

**All terminal commands must be run from this directory** (`Ansible Lab/`), where `ansible.cfg` is located.
