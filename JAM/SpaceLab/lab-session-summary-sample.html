Executive Summary

This lab session modernized the ISS Travel App from IBM WebSphere Application Server 9 (Java 8, Java EE 7, EAR+WAR) to Open Liberty 24.0.0.6 (Java 17, Jakarta EE 8, WAR-only). Six sequential Bob prompts drove the work: assessment, planning, implementation, runtime verification, dependency audit, and final reporting.

All four REST API contracts, all JSON response shapes, all four pre-loaded sample travel records, and the full browser UI are preserved without alteration. The only frontend change was updating three technology-label badges in index.html.

The root cause of the original build failure (was-public-api:9.0 system-scope dependency requiring WAS_HOME) was removed. No IBM-proprietary classes remain in any source file. The compiled WAR carries bytecode major version 61 (Java 17).
