ISS Travel App — Modernization Final Report

Migration: IBM WebSphere 9 / Java 8 / Java EE 7  →  Open Liberty / Java 17 / Jakarta EE 8  ·  September 2026

Executive Summary

The ISS Travel App has been successfully modernized from its legacy IBM WebSphere Application Server 9 / Java 8 target to a portable Open Liberty / Java 17 stack. All WebSphere-specific runtime APIs have been replaced with standard Servlet 4.0 equivalents. The EAR packaging layer has been eliminated. All three IBM-specific deployment descriptors have been deleted. The Maven build now completes cleanly under Java 17 with no warnings, and all four REST endpoints have been verified live on Open Liberty.

No business logic, data model, or browser UI was altered. The four seeded travel records and the Add Travel Request form (with immediate table refresh) work identically to the legacy application.
