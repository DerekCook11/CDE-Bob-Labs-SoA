## Accessing Bob Via TechZone

To access Bob, we will be using TechZone VMs which will be shared with each participant.

When accessing TechZone you will want to navigate to your requests which will contain the VM. 

![[step-1.jpg]]

After expanding the environment details you will see the username and password as well as the link to open the VM within your web browser. Go ahead and copy the password as we will use it later.

![[step-2.jpg]]

The new page you are taken to will be for the VM, go ahead and click on the console which will open the remote desktop experience.

![[step-3.jpg]]

Go ahead and click to connect. The username and password will be  automatically populated on this page.

![[step-4.jpg]]

Once connected you will be taken to the RedHat Enterprise Linux VM. If you are not directly logged in, and you do not immediately see the login page, you will need to interact and click somewhere on the screen to see the login prompt. You will need to use the login credentials from the TechZone reservation page. In the top of the VM remote desktop page there is an option to send text from the host machine to the remote desktop. **If you try and copy and paste text from your host machine to VM it will fail. You MUST use the _"Send Text to VM" option which will allow you to copy and paste text from your host machine to the VM.

![[step-5.jpg]]

Once logged in, you will navigate to your applications by going to the top left, clicking on activities which will bring the bottom row of applications into view. From here you will click on the grid which will show you all applications which include IBM Bob.

![[step-6.jpg]]

Once your Bob IDE is open, you will need to open the Bob panel by clicking on the icon labeled 1. From here the Bob panel will allow you to login.

![[step-7.jpg]]

You will be redirected to the Bob login webpage which will allow you to use your IBM ID to authenticate.

![[step-8.jpg]]

Once your login is completed you will be prompted to open a link which will return to the Bob IDE. At this point you can close the web browser and return to Bob.

![[step-9.jpg]]

Within Bob you will now see that you have been logged in. At the bottom of the panel there is now a chat interface which will be used during your agentic development process. Additional settings for Bob can be found by clicking the settings button which is where you would be able to further configure settings for Bob, including MCP servers, custom modes, and skills.
