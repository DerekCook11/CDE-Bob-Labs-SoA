Application Architecture & Request Flow

A two-tier web app. The static frontend communicates with a Flask REST API backed by a local SQLite file. No auth layer, no reverse proxy, no build step exist in the original.

Browser (index.html + app.js)
  │  fetch() JSON over HTTP — port 5000
  ▼
Flask API (app.py)
  │  sqlite3.execute(SQL, params)
  ▼
SQLite (tasks.db)     ←—  config.py (secrets loaded at startup)
FilePurpose
backend/config.pyRuntime settings — secrets, DB path, CORS origins, debug flag, host/port
backend/database.pySQLite lifecycle: open/close per-request via Flask g, schema creation, seed rows
backend/app.pyAll HTTP routes (health, tasks CRUD, search, admin) and global error handler
frontend/index.htmlStatic shell — task form, search bar, task-list container
frontend/app.jsAll browser logic — API calls, DOM rendering, event wiring
frontend/styles.cssPure CSS, dark theme — no logic, no user data

Attack Chain (Before Remediation)

All findings combine into a complete unauthenticated compromise path:

1

GET /api/admin/config — no auth required  F-02 + F-03

Returns SECRET_KEY, ADMIN_PASSWORD, and API_KEY in one unauthenticated response. Wildcard CORS (F-07) means any web page can trigger this cross-origin.

2

Forge Flask session cookie with SECRET_KEY  F-03 + F-08

Debug mode also activates the Werkzeug interactive debugger — arbitrary Python RCE on any unhandled exception.

3

SQL Injection via search  F-01 + F-06

?q=' UNION SELECT … reads or destroys the entire database. Verbose errors (F-06) reveal schema, reducing effort.

4

Store XSS payload via POST /api/tasks  F-04 + F-09

Payload executes in every browser loading the task list — persistent, affects all users.

5

Server reachable from the internet  F-10

Default bind 0.0.0.0 on a cloud VM exposes all findings globally without any firewall change.

F-01 — SQL Injection in Search Endpoint

CriticalCWE-89OWASP A03:2021app.py:100Fixed

Evidence: The q query-string parameter was f-string interpolated directly into a SQL string — never parameterized.

Before — vulnerable-app/backend/app.py:97–102
After — secure-app/backend/app.py
query = request.args.get("q", "") sql = f"SELECT * FROM tasks WHERE title LIKE '%{query}%' ORDER BY id DESC" rows = get_db().execute(sql).fetchall()
query = request.args.get("q", "") rows = get_db().execute( "SELECT * FROM tasks WHERE title LIKE ? ORDER BY id DESC", (f"%{query}%",), ).fetchall()

Exploitation scenario:
GET /api/tasks/search?q=' UNION SELECT id,secret_key,admin_password,0,datetime('now') FROM sqlite_master--
Reads any table. A DROP TABLE variant destroys all data.

Regression tests: TestF01SQLInjection — 4 pytest tests: UNION injection, OR bypass, DROP TABLE attempt, normal search still works. Also covered by test_sql_injection_does_not_bypass_search in the external regression suite.

F-02 — Unauthenticated Config Endpoint

CriticalCWE-200OWASP A02:2021app.py:114Fixed

Evidence: GET /api/admin/config returned all three secrets to any unauthenticated HTTP client.

Before — app.py:114–124
After — route deleted entirely
@app.get("/api/admin/config") def expose_config(): return jsonify({ "secret_key": config.SECRET_KEY, "admin_password": config.ADMIN_PASSWORD, "api_key": config.API_KEY, "debug": config.DEBUG, })
# Route and handler deleted in their entirety. # GET /api/admin/config now returns 404. # # Error handler also fixed to re-raise # HTTPException so 404 is not swallowed # into a generic 500.

Exploitation: curl http://target:5000/api/admin/config — all secrets in one unauthenticated GET, combinable with wildcard CORS (F-07) to exfiltrate from any browser tab.

Regression tests: TestF02ConfigEndpointRemoved (2 tests) + test_config_endpoint_does_not_expose_secrets in external suite.

F-03 — Hardcoded Credentials and API Key

CriticalCWE-798OWASP A07:2021config.py:13Fixed
Before — config.py (all six bad defaults)
After — config.py (env-var driven)
SECRET_KEY = "training-secret-key-please-change" ADMIN_PASSWORD = "BobLabAdmin123!" API_KEY = "sk_training_51ABCDEF_not_a_real_key" CORS_ORIGINS = "*" DEBUG = True HOST = os.getenv("APP_HOST", "0.0.0.0")

This single config rewrite also fixes F-07 (wildcard CORS), F-08 (debug on), and F-10 (0.0.0.0). The app refuses to start if any required variable is absent. .env.example updated: no real or fake secrets anywhere in source.

Regression tests: TestF03HardcodedCredentials — 5 tests: no hardcoded strings, _require_env raises on missing var, reads from env, debug defaults to False, host defaults to loopback.

F-04 — Stored XSS via innerHTML

HighCWE-79OWASP A03:2021app.js:35Fixed
Before — app.js renderTasks() lines 35–47
After — app.js buildTaskCard()
taskList.innerHTML = tasks.map((task) => ` <article class="task"> <h3>${task.title}</h3> <p>${task.description}</p> <button onclick="deleteTask(${task.id})"> Delete </button> </article> `).join('');
function buildTaskCard(task) { const h3 = document.createElement('h3'); h3.textContent = task.title; // never HTML-parsed const p = document.createElement('p'); p.textContent = task.description || 'No description'; const btn = document.createElement('button'); btn.textContent = 'Delete'; btn.addEventListener('click', () => deleteTask(task.id)); // innerHTML is not used anywhere in the render path }

F-05 — API Key Returned on Auth Success

HighCWE-200OWASP A02:2021app.py:110Fixed
Before — verify_admin()
After — verify_admin()
if payload.get("password") == config.ADMIN_PASSWORD: return jsonify({ "authenticated": True, "api_key": config.API_KEY # ← secret in response })
import hmac match = hmac.compare_digest( provided.encode("utf-8"), config.ADMIN_PASSWORD.encode("utf-8"), ) if match: return jsonify({"authenticated": True}) # No secret fields in any response

hmac.compare_digest runs in constant time — eliminates timing-based oracle attacks that allow byte-by-byte password enumeration via response latency.

Regression tests: TestF05AdminVerifyNoSecretLeak — 5 tests: success without api_key, success without secret_key, wrong password → 401, null body → 401 not 500.

F-06 — Verbose Error Handler Leaks Internals

HighCWE-209OWASP A05:2021app.py:127Fixed
Before — handle_unexpected_error()
After
return jsonify({ "error": "Unexpected server error", "details": str(error), # ← exception text to caller "type": type(error).__name__ # ← class name to caller }), 500
from werkzeug.exceptions import HTTPException if isinstance(error, HTTPException): return error # preserve 4xx codes (e.g. 404) logger.exception("Unhandled exception: %s", error) return jsonify({ "error": "An unexpected error occurred." }), 500

Stack traces and exception class names go to the server-side Python logger only. The body.details fallback was also removed from the frontend api() wrapper so internal text can never surface in the browser UI.

Regression tests: TestF06VerboseErrorHandler — 2 tests: null body → 400 not 500, no details/type keys in any error response.

F-07 — Wildcard CORS Policy

MediumCWE-942OWASP A05:2021config.py:21Fixed

Before: CORS_ORIGINS = "*" — any origin could cross-fetch the API from inside a victim's browser tab.

After (config.py):

_raw = os.getenv("ALLOWED_ORIGINS", "http://localhost:8080")
CORS_ORIGINS = [o.strip() for o in _raw.split(",") if o.strip()]
CORS(app, origins=config.CORS_ORIGINS)   # explicit list, never "*"

Regression tests: TestF07CORSPolicy — 3 tests: allowed origin gets matching ACAO header, wildcard never returned, disallowed origin gets no ACAO.

F-08 — Debug Mode Enabled by Default

MediumCWE-94OWASP A05:2021config.py:22Fixed

Before: DEBUG = True — activates Werkzeug's interactive debugger: arbitrary Python execution from any browser on an unhandled exception.

After: DEBUG = os.getenv("FLASK_DEBUG", "false").lower() == "true" — off by default, opt-in only via environment.

Regression tests: TestF08DebugMode — 1 test: asserts config.DEBUG is False when FLASK_DEBUG is unset.

F-09 — No Input Validation on Create / Update

MediumCWE-20OWASP A03:2021app.py:45Fixed

Before: payload = request.get_json() with no checks — a null body caused AttributeError (leaked by F-06), non-string types were silently coerced, unbounded lengths enabled storage DoS.

After — shared validator exported alongside a named constant:

MAX_TITLE_LENGTH = 200
MAX_DESCRIPTION_LENGTH = 2000

def validate_task_payload(payload):
    if not isinstance(payload, dict):              return "Request body must be a JSON object.", 400
    title = payload.get("title")
    if not isinstance(title, str) or not title.strip(): return "title must be a non-empty string.", 400
    if len(title) > MAX_TITLE_LENGTH:              return f"title must be ≤{MAX_TITLE_LENGTH} chars.", 400
    description = payload.get("description", "")
    if not isinstance(description, str):           return "description must be a string.", 400
    if len(description) > MAX_DESCRIPTION_LENGTH:  return "description too long.", 400
    completed = payload.get("completed", False)
    if not isinstance(completed, bool):            return "completed must be a boolean.", 400
    return None, None

Regression tests: TestF09InputValidation — 16 tests: null body, missing title, empty title, integer title, list title, title over limit, description over limit, non-string description, non-boolean completed, valid payload (201), update variants, unit tests for the validator directly, and MAX_TITLE_LENGTH export. Also covered by test_blank_title_is_rejected and test_non_boolean_completed_is_rejected in the external suite.

F-10 — Server Bound to 0.0.0.0 by Default

LowCWE-668OWASP A05:2021config.py:24Fixed

Before: HOST = os.getenv("APP_HOST", "0.0.0.0") — on a cloud VM with a public IP, all findings became internet-reachable without any firewall change.

After: HOST = os.getenv("APP_HOST", "127.0.0.1") — loopback by default; operators who need external access must explicitly set APP_HOST.
